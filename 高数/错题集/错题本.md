# 高等数学 · 错题本

> 这是高数错题的**唯一数据源**。每次做完题，把错题按下面格式追加进去；需要复习时运行 `D:\专升本学习\错题本\build.py`（或直接让我来更新），会自动生成同目录 `复习页.html`。
> **本页支持 LaTeX 公式**：行内公式用 `$...$`（如 `$f'(x)$`），独立公式用 `$$...$$`，复习页会用 KaTeX 自动渲染。

---

## 一、格式说明

- 每条错题用 `## Q-序号` 开头，序号递增。
- 每个字段用 `- 字段名：值` 单独一行（中英文冒号均可）。
- **可用字段**（不涉及的可以不写）：

| 字段 | 必填 | 说明 |
| --- | --- | --- |
| 章节 | 必填 | 见下方章节预设 |
| 题目 | 必填 | 支持 LaTeX 公式 |
| 答案 | 必填 | 支持公式 |
| 解析 | 推荐 | 把**解题步骤、易错点**写进去，支持公式，可用换行分段 |
| 选项 | 选填 | `A. xx / B. xx / C. xx / D. xx` 斜杠分隔 |
| 题型 | 选填 | 选择 / 填空 / 计算 / 证明 / 判断 |
| 知识点 | 选填 | 如"洛必达法则" |
| 错因 | 选填 | 概念不清 / 计算失误 / 公式记错 / 方法不会 / 粗心 |
| 错误次数 | 选填 | 重复做错几次就写几（默认 0，>0 会进"重点题"） |
| 日期 | 选填 | 做错日期 |
| 状态 | 选填 | 待复习 / 已掌握 |

> 多行内容（如解析里分步骤）可直接换行继续写，脚本会保留换行。
