## 一、格式说明

- 每条错题用 `## Q-序号` 开头，序号递增。
- 每个字段用 `- 字段名：值` 单独一行（中英文冒号均可）。
- **可用字段**（不涉及的可以不写）：

| 字段 | 必填 | 说明 |
| --- | --- | --- |
| 章节 | 必填 | 见下方章节预设 |
| 题目 | 必填 | 支持 LaTeX 公式 |
| 答案 | 必填 | 支持公式 |
| 解析 | 推荐 | 把**解题步骤、易错点**写进去，支持公式，可用换行分段 |
| 选项 | 选填 | `A. xx / B. xx / C. xx / D. xx` 斜杠分隔 |
| 题型 | 选填 | 选择 / 填空 / 计算 / 证明 / 判断 |
| 知识点 | 选填 | 如"洛必达法则" |
| 错因 | 选填 | 概念不清 / 计算失误 / 公式记错 / 方法不会 / 粗心 |
| 错误次数 | 选填 | 重复做错几次就写几（默认 0，>0 会进"重点题"） |
| 日期 | 选填 | 做错日期 |
| 状态 | 选填 | 待复习 / 已掌握 |

> 多行内容（如解析里分步骤）可直接换行继续写，脚本会保留换行。

## Q-001
- 章节：02-导数与微分
- 日期：2026-09-05
- 状态：待复习
- 题型：填空
- 错因：公式记错
- 题目：设 $f(x)=x^2 e^x$，求 $f'(x)$。
- 答案：$f'(x)=xe^x(x+2)$
- 解析：由乘法法则：
$$(uv)'=u'v+uv'$$
令 $u=x^2,\ v=e^x$，则 $f'(x)=2x e^x + x^2 e^x = xe^x(x+2)$。
易错点：$e^x$ 的导数是它本身，不要写成 $e^{x-1}$。
- 知识点：乘积求导法则

## Q-003
- 章节：02-导数与微分
- 日期：2026-09-06
- 状态：待复习
- 题型：简答
- 题目：求微分方程 $y'-2y=e^{2x}$ 的通解。
- 答案：$y=(x+C)e^{2x}$
- 解析：一阶线性非齐次，$p=-2$，积分因子 $e^{-2x}$，$(ye^{-2x})'=1$，故 $ye^{-2x}=x+C$。 （来源：自编自测（原题选项有误，改用规范通解形式））
