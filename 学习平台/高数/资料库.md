## 一、考试基本信息

| 项目 | 内容 |
| --- | --- |
| 适用考生 | 理工农医类 |
| 考试科目组合 | 高等数学 + 大学英语 + 计算机基础 |
| 满分 | 150 分 |
| 考试时间 | 120 分钟 |
| 考试形式 | 闭卷、笔试 |
| 试卷内容结构 | 线性代数约占 20%，其他（高等数学）约占 80% |

## 二、考试范围（官方）

考试范围包括《高等数学》和《线性代数》两大部分：

- **高等数学**：函数、极限、连续；一元函数微分学；一元函数积分学；向量代数与空间解析几何；多元函数微分学与二重积分；无穷级数；常微分方程
- **线性代数**：行列式、矩阵、向量、线性方程组

## 三、考试题型（官方）

判断题、单选题、填空题、计算题、解答题、证明题、应用题等形式。
难度分四档：容易题、较易题、中等难度题、较难题，试卷总体难度适中。

> 按近年考情：客观题约 40%，计算/应用/证明等主观题约 60%。

## 四、分模块考点清单（对照考纲）

### 1. 函数、极限与连续
- 函数概念、定义域、单调性/奇偶性/有界性/周期性；反函数；复合函数
- 极限概念与四则运算；两个重要极限；夹逼准则；无穷小/无穷大、等价无穷小
- 连续性、间断点及类型；闭区间连续函数性质（最值/介值/零点定理）

### 2. 一元函数微分学
- 导数概念与几何意义；切线/法线；基本求导公式、四则与复合求导
- 隐函数、参数方程求导、对数求导；高阶导数；微分
- 罗尔/拉格朗日中值定理；洛必达法则（各种未定式）
- 单调性与极值/最值；凹凸性与拐点；渐近线（水平/垂直）

### 3. 一元函数积分学
- 原函数与不定积分、基本积分公式；第一/第二换元法、分部积分法
- 定积分概念与性质、变限积分求导、牛顿-莱布尼茨公式
- 定积分换元与分部；广义积分；面积与旋转体体积

### 4. 向量代数与空间解析几何
- 向量坐标、单位向量、方向余弦；数量积、向量积；平行/垂直条件
- 平面方程、点到平面距离；直线方程与位置关系
- 柱面、旋转曲面、常见二次曲面

### 5. 多元函数微分学与二重积分
- 偏导数、全微分、复合函数求导、隐函数偏导
- 空间曲线切线与法平面、曲面切平面与法线
- 极值、拉格朗日乘数法；二重积分（直角/极坐标、交换次序）

### 6. 无穷级数
- 级数收敛/发散；正项级数判别法（比较/比值/根值）；几何级数、p 级数
- 莱布尼茨判别法；绝对收敛与条件收敛
- 幂级数收敛半径/区间；逐项求导积分；常用麦克劳林展开式

### 7. 常微分方程
- 可分离变量方程、齐次方程、一阶线性方程
- 二阶常系数齐次线性方程；二阶常系数非齐次线性方程特解设法

### 8. 线性代数
- 行列式性质与按行（列）展开
- 矩阵运算、逆矩阵（伴随矩阵法/初等变换法）、矩阵秩
- 向量组线性相关/无关、极大无关组与秩
- 克莱姆法则、线性方程组解的判定与通解

## 五、高频考点与命题特点（综合近年考情）

1. **极限计算**是绝对高频：洛必达法则、等价无穷小、两个重要极限、变限积分求极限
2. **导数应用**：单调区间、极值最值、凹凸拐点、中值定理证明题
3. **定积分**：变限积分求导、换元分部、面积体积应用
4. **二重积分**：直角/极坐标计算、交换积分次序
5. **线代约占 20 分**：行列式计算、逆矩阵、线性方程组解的结构是常考
6. 证明题常用：零点定理、罗尔/拉格朗日中值定理

## 八、备考建议

1. **先过考纲**：按上面的八模块清单逐项核对"了解/理解/掌握/熟练掌握"要求，明确哪些要会算、哪些要会证明
2. **重计算、稳主观题**：主观题占 60%，平时一定要动手完整写出计算/证明过程，不要只看答案
3. **刷题配套**：配合《题库.md》分专题刷题，错题及时写入错题集《错题本.md》
4. **线代别放弃**：占 20 分，行列式、矩阵、方程组这三块性价比高
5. **考前**：把错题本的"重点题"和"今日应复习"刷一遍，重点背公式（等价无穷小、积分表、麦克劳林展开式、微分方程特解设法）

## 九、各模块核心公式与方法速查（考前冲刺用）

### 1. 函数、极限与连续
- **等价无穷小**（$x\to0$）：$\sin x\sim x$、$\tan x\sim x$、$\arcsin x\sim x$、$1-\cos x\sim \frac12x^2$、$\ln(1+x)\sim x$、$e^x-1\sim x$、$(1+x)^\alpha-1\sim\alpha x$
- **两个重要极限**：$\lim\limits_{x\to0}\frac{\sin x}{x}=1$；$\lim\limits_{x\to\infty}(1+\frac1x)^x=e$（推广 $\lim(1+\frac{k}{x})^x=e^k$）
- **洛必达法则**：$\frac00$ 或 $\frac\infty\infty$ 型才可用，分子分母分别求导
- **连续定义**：$\lim\limits_{x\to x_0}f(x)=f(x_0)$；间断点分第一类（可去/跳跃）、第二类（无穷/振荡）

### 2. 一元函数微分学
- **基本导数**：$(x^n)'=nx^{n-1}$、$(e^x)'=e^x$、$(a^x)'=a^x\ln a$、$(\ln x)'=\frac1x$、$(\sin x)'=\cos x$、$(\cos x)'=-\sin x$、$(\tan x)'=\sec^2x$
- **链式法则**：$[f(g(x))]'=f'(g(x))g'(x)$
- **中值定理**：罗尔（$f(a)=f(b)$→存在 $f'(\xi)=0$）；拉格朗日（$f(b)-f(a)=f'(\xi)(b-a)$）；柯西
- **极值判定**：一阶导变号法 / $f''(x_0)<0$ 极大、$>0$ 极小；**最值**：比较端点和驻点
- **常用技巧**：隐函数求导（两边对 x 求导）、参数方程求导、对数求导法

### 3. 一元函数积分学
- **基本积分**：$\int x^n dx=\frac{x^{n+1}}{n+1}+C$、$\int e^x dx=e^x+C$、$\int\frac1x dx=\ln|x|+C$、$\int\frac1{1+x^2}dx=\arctan x+C$、$\int\sin x\,dx=-\cos x+C$
- **分部积分**：$\int u\,dv=uv-\int v\,du$（选 $u$：反对幂指三）
- **牛顿-莱布尼茨**：$\int_a^b f(x)dx=F(b)-F(a)$
- **几何应用**：面积 $S=\int_a^b[f(x)-g(x)]dx$；旋转体体积 $V=\pi\int_a^b[f^2(x)-g^2(x)]dx$（绕 x 轴，外平方减内平方）

### 4. 向量代数与空间解析几何
- 点积 $a\cdot b=|a||b|\cos\theta$；叉积结果垂直于 $a,b$
- 平面：$A(x-x_0)+B(y-y_0)+C(z-z_0)=0$；直线：对称式/参数式
- 两平面垂直 $\iff$ 法向量点积为 0；平行 $\iff$ 法向量成比例

### 5. 多元函数微分学与二重积分
- 偏导：对谁求导把其他变量当常数；全微分 $dz=f_xdx+f_ydy$
- 二重积分：直角坐标（先定 $y$ 范围再 $x$，或反之）；极坐标 $d\sigma=rdrd\theta$（圆域优先）

### 6. 无穷级数
- 正项级数：比较审敛、比值审敛 $\lim\frac{u_{n+1}}{u_n}=\rho$（$<1$ 收敛）、根值审敛
- 交错级数：莱布尼茨（单调递减趋于 0 则收敛）
- 幂级数收敛半径：$R=\lim\left|\frac{a_n}{a_{n+1}}\right|$
- **麦克劳林展开**：$e^x=1+x+\frac{x^2}{2!}+\cdots$、$\ln(1+x)=x-\frac{x^2}2+\frac{x^3}3-\cdots$、$\sin x=x-\frac{x^3}{3!}+\cdots$

### 7. 常微分方程
- 一阶可分离：$\frac{dy}{dx}=g(x)h(y)$ → 分离变量两边积分
- 一阶线性：$y'+P(x)y=Q(x)$，通解 $y=e^{-\int Pdx}[\int Qe^{\int Pdx}dx+C]$
- 二阶常系数齐次 $y''+py'+qy=0$：特征方程 $r^2+pr+q=0$，两不等实根 $y=C_1e^{r_1x}+C_2e^{r_2x}$；重根 $y=(C_1+C_2x)e^{rx}$；共轭复根 $y=e^{\alpha x}(C_1\cos\beta x+C_2\sin\beta x)$
- 非齐次特解设法：按 $f(x)$ 形式设，含共振时乘 $x^k$

### 8. 线性代数
- **行列式**：上/下三角 = 主对角积；按行展开 $|A|=\sum a_{ij}A_{ij}$；$|AB|=|A||B|$
- **矩阵**：$A^{-1}=\frac1{|A|}A^*$（$|A|\ne0$ 可逆）；$(AB)^T=B^TA^T$；$|kA|=k^n|A|$
- **秩**：非零子式最高阶数；$r(AB)\le\min(r(A),r(B))$
- **方程组**：$AX=b$ 有解 $\iff r(A)=r(A|b)$；齐次 $AX=0$ 非零解 $\iff r(A)<n$
- **特征值**：$|\lambda I-A|=0$；特征值之和 = 迹，之积 = $|A|$
