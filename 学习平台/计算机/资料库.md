## 四、分模块考点清单（对照官方考纲）

### 1. 计算机基础知识（15%）
- 计算机概念、发展历史、特点、分类、应用
- 数制与转换：二进制/八进制/十进制/十六进制互转
- 数值数据与字符数据表示；计算机信息单位（bit/Byte/KB/MB/GB）
- ASCII 码、汉字编码（GB2312、机内码、字形码、Unicode）

### 2. 计算机软硬件基础（20%）
- 冯·诺依曼体系结构；总线、主板
- 五大部件：运算器、控制器、存储器、输入/输出设备
- 软件系统：系统软件/应用软件；操作系统功能（处理机/存储/设备/文件管理）
- Windows 基本操作：图标/窗口/菜单、资源管理、任务管理、文件管理
- 数字媒体：音频/视频/图像数字化

### 3. 办公自动化（35%）
- **Word**：文档创建编辑、字体/段落/页面设置、分栏、表格、图片/文本框/艺术字/SmartArt、图文混排、目录、邮件合并、打印
- **Excel**：工作簿/工作表、单元格引用（相对/绝对/混合）、公式与常用函数（ABS、SUM、SUMIF、AVERAGE、COUNT、COUNTIF、VLOOKUP、IF、MAX、MIN、RANK、MID、LEFT、RIGHT、MOD 等）、图表、排序/筛选/分类汇总
- **PPT**：创建、视图、幻灯片基本操作、主题与背景、动画/切换/放映、打包共享

### 4. 网络与信息安全（10%）
- 网络概念、分类（LAN/MAN/WAN）、体系结构、拓扑结构
- Internet：IP 地址、域名、主要服务；信息检索、电子邮件
- 信息安全：病毒特征与防范、防火墙、个人信息安全

### 5. 算法与程序设计（10%）
- 计算思维；算法特征与复杂度
- 三种基本结构（顺序/选择/循环）
- 程序流程图；累加、累乘、顺序查找、二分查找、冒泡排序思想
- Python 程序设计初步（近年命题趋向）

### 6. 数据库技术（5%）
- 数据管理发展；数据库系统概念；数据模型
- E-R 图；关系运算（选择/投影/连接）；常用 DBMS（Access/SQL Server/MySQL/Oracle）；SQL 基础

### 7. 计算机新技术（5%）
- 云计算（部署模式、IaaS/PaaS/SaaS）
- 大数据（特征、应用、安全）
- 物联网（感知层/网络层/应用层）
- 人工智能（定义、应用、伦理）

## 九、计算题速算方法与操作要点（考前冲刺用）

### 1. 进制转换速算
- **二进制→十进制**：按位权展开 $b_n2^n+\cdots+b_02^0$
- **十进制→二进制**：短除法（除以 2 取余，逆序排列）
- **二/八/十六互转**：3 位二进制=1 位八进制，4 位二进制=1 位十六进制（不足补 0，从右往左分组）
- **记忆**：$2^{10}=1024$、$2^{8}=256$、$2^{16}=65536$；十六进制 A=10、B=11、C=12、D=13、E=14、F=15

### 2. 原码 / 反码 / 补码
- 正数：三者相同；负数：反码=原码除符号位按位取反，补码=反码+1
- **补码的意义**：把减法变加法；8 位补码范围 $-128\sim127$
- 求 $-5$ 的 8 位补码：$00000101$ → 取反 $11111010$ → 加 1 得 $11111011$

### 3. 存储容量换算
- $1B=8bit$；$1KB=1024B$；$1MB=1024KB$；$1GB=1024MB$；$1TB=1024GB$
- 汉字内码占 **2 字节**（GB2312/GBK）；一个 ASCII 字符占 1 字节
- 示例：$8GB$ 可存汉字 $8\times1024^3\div2\approx42.9$ 亿个

### 4. 网络与子网划分
- IP 地址 32 位，分四段；掩码中 1 表示网络位、0 表示主机位
- 子网主机数 $=2^{主机位数}-2$（减去网络号和广播地址）
- 记忆：/24 → 254 台；/25 → 126 台；/26 → 62 台；/27 → 30 台；/28 → 14 台

### 5. 数据库 SQL 速记
- 查询：`SELECT 列 FROM 表 WHERE 条件 GROUP BY 分组 ORDER BY 排序[ASC升/DESC降]`
- 聚合：`COUNT(*)` 计数、`SUM` 求和、`AVG` 平均、`MAX/MIN` 最大最小
- 插入/更新/删除：`INSERT INTO`、`UPDATE ... SET`、`DELETE FROM ... WHERE`

### 6. 算法与数据结构速记
- 时间复杂度：顺序 $O(n)$、二分 $O(\log_2n)$、冒泡/选择 $O(n^2)$、快速平均 $O(n\log_2n)$
- 栈：后进先出 LIFO；队列：先进先出 FIFO
- 二分查找前提：**有序**线性表；二叉树遍历：先/中/后序

### 7. Word / Excel / PPT 高频操作路径（操作题写步骤）
- **Word**：改字体（选中→开始→字体）；首行缩进（段落→特殊格式→首行缩进 2 字符）；查找替换（Ctrl+H）；页眉页码（插入→页眉/页码）；插入表格（插入→表格）；分页（Ctrl+Enter）
- **Excel**：公式以 `=` 开头；求和 `=SUM(A1:A10)`；平均 `=AVERAGE()`；排名 `=RANK(值,区域)`；查找 `=VLOOKUP()`；相对/绝对引用（$ 固定）；排序筛选（数据选项卡）；冻结窗格（视图选项卡）
- **PPT**：幻灯片版式（开始→版式）；母版（视图→幻灯片母版）；切换效果（切换选项卡）；动画（动画选项卡）；放映（F5）
