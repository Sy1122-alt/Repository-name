# 英语 · 生词本

> 这是**生词汇总的数据源之一**（手动维护用）。
> - 网页版《单词本.html》里给单词「标星」的生词会自动出现在《生词本.html》里，无需手动编辑本文件；
> - 想把某些词固定记录下来（不依赖浏览器记忆），可以手动按下面格式加在这里，运行 `错题本/build.py` 后同样会出现在《生词本.html》；
> - 在《生词本.html》点「⬇ 导出」可以一键把当前生词按本格式生成文件，直接替换本文件即可备份。

---

## 一、格式说明

- 每个生词用 `## W-序号` 开头，序号递增。
- 每个字段用 `- 字段名：值` 单独一行。
- **可用字段**：

| 字段 | 必填 | 说明 |
| --- | --- | --- |
| 单词 | 必填 | 英文单词/短语 |
| 释义 | 必填 | 中文释义 |
| 音标 | 选填 | `/əˈbændən/` |
| 词性 | 选填 | v. / n. / adj. 等 |
| 例句 | 选填 | 帮助记忆的句子 |
| 状态 | 选填 | 待复习 / 已掌握 / 模糊 |
