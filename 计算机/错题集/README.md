## 日常使用闭环

1. **出题**：你说一声，我按章节/考纲出题（单选/填空/判断/简答都行）。
2. **作答**：你答题，把拿不准或做错的告诉我。
3. **入库**：我把错题按格式写进 `错题本.md`。
4. **刷新复习页**：运行 `D:\专升本学习\错题本\build.py`（或让我代跑），`复习页.html` 自动更新。
5. **复习**：双击 `复习页.html` → 随机抽题 → 显示答案 → 标"已掌握/待复习"（进度存在浏览器里，下次打开还在）。

复习页进阶功能：`重点题`（错误次数≥2 自动筛出）、`今日应复习`（按错误次数与最近复习间隔推荐）、错因分布统计。

## 在 MD 里追加错题的格式（每条一个 `## Q-序号`）

```markdown
## Q-001
- 章节：06-计算机网络
- 日期：2026-09-05
- 状态：待复习
- 题型：单选
- 错因：概念不清
- 题目：OSI 参考模型共有几层？
- 选项：A. 4 / B. 5 / C. 6 / D. 7
- 答案：D
- 解析：OSI 七层模型：物理、数据链路、网络、传输、会话、表示、应用。
- 知识点：OSI 参考模型
- 错误次数：1
```

- 字段都可以不写（除了 `章节`、`题目`、`答案`），无选项题就不写"选项"。
- 状态：`待复习` / `已掌握`，不写默认待复习。`错误次数` 重复做错就 +1，会进"重点题"。
- 在 `复习页.html` 里点的"已掌握/待复习"只存在浏览器本地；想让 MD 里的状态也同步，告诉我，我帮你回写。
