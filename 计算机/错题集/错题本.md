# 计算机错题本

> 这是错题的**唯一数据源**（Markdown 文件）。每次做完题，把错题按下面的格式追加进去；需要复习时运行 `D:\专升本学习\错题本\build.py`（或直接让我来更新），会自动生成可双击打开的 `复习页.html`。你只负责做题和看复习页，格式维护交给脚本。
> 已升级：新增「题型 / 错误次数」字段（重复做错会进"重点题"），复习页支持错因分布、今日应复习推荐。

---

## 一、格式说明

- 每条错题用 `## Q-序号` 开头，序号递增（Q-001、Q-002……）。
- 每个字段用 `- 字段名：值` 单独一行，注意中英文冒号都可以，脚本都能识别。
- **可用字段**（不涉及的字段可以不写，比如无选项题就不写"选项"）：

| 字段 | 必填 | 说明 |
| --- | --- | --- |
| 章节 | 必填 | 见下方章节预设，可自行增改 |
| 题目 | 必填 | 题目内容 |
| 答案 | 必填 | 正确答案 |
| 解析 | 推荐 | 为什么对/为什么错，越详细越利于复习 |
| 选项 | 选填 | 用 `A. xxx / B. xxx / C. xxx / D. xxx` 斜杠分隔 |
| 题型 | 选填 | 单选 / 判断 / 填空 / 简答 |
| 知识点 | 选填 | 关联考点，如"进制转换" |
| 错因 | 选填 | 概念不清 / 计算失误 / 粗心 / 理解偏差 / 其他 |
| 错误次数 | 选填 | 重复做错几次写几（默认 0，>0 会进"重点题"） |
| 日期 | 选填 | 做错日期，如 2026-09-05 |
| 状态 | 选填 | 待复习 / 已掌握，默认待复习 |
