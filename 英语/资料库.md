# 大学英语 · 四川专升本题库与资料

> 整理时间：2026-09-05。汇总四川专升本《大学英语》官方考纲、题型与备考要点。
> ⚠️ 时效提示：现行考纲沿用 2024 版；最新政策以 **四川省教育考试院（sceea.cn）** 发布为准。
> 💡 特点：**不考听力**，难度介于英语 A 级与四级之间，客观题占大头（约 70%）。

## 一、考试基本信息

| 项目 | 内容 |
| --- | --- |
| 适用考生 | 理工农医类 & 非理工农医类（必考） |
| 满分 | 150 分 |
| 考试时间 | 120 分钟 |
| 考试形式 | 闭卷、笔试 |
| 题分结构 | 客观题约占 70%，主观题约占 30% |

## 二、考试题型（官方，每次考试从下列题型中选取组卷）

补全对话、词汇与语法结构（单选题）、阅读理解、选词填空、选句填空、完形填空、短文改错、英译汉、汉译英、短文写作（不少于 100 词）。

## 三、分模块考点

### 1. 语言知识（词汇+语法）
- **词汇**：约 3500 核心词 + 固定搭配、短语辨析
- **语法**（约 22 类高频考点）：
  - 时态语态（一般/进行/完成/将来等）
  - 非谓语动词（不定式/动名词/分词）
  - 三大从句（定语从句、名词性从句、状语从句）
  - 虚拟语气（含 suggest 等 + should 原形、if 虚拟）
  - 主谓一致（neither...nor、as well as、the only one of...）
  - 倒装（Never/Hardly 开头部分倒装）
  - 强调句、反意疑问句、冠词、介词短语、情态动词等

### 2. 阅读
- 阅读理解：4 篇短文，考细节、主旨、词义猜测、推理判断
- 题材：科技、文化、人物、社会等（如航天、非遗、表情符号研究）

### 3. 写作
- 短文写作：不少于 100 词
- 常考类型：观点/议论文、书信、通知、利弊分析等
- 评分看：内容切题、语言正确、结构清晰、字数达标

## 四、高频考点与命题特点

1. **词汇辨析**：近义词（bring/take/carry/fetch）、固定搭配（take advantage of、attach importance to）
2. **时态语态**：延续性动词（have/had been on）与瞬间动词（start）的区分
3. **非谓语**：It is + adj. + for sb. + to do；have sb. do sth.；suggest doing
4. **虚拟语气**：suggest/insist 等 + (should) + 动词原形；It is high time + 过去式
5. **从句**：the only one of + 复数名词 + 定语从句谓语用单数
6. **倒装**：Hardly...when...；Never have I seen...；only+状语 部分倒装
7. **主谓一致**：as well as/together with 不影响主语单复数；neither...nor 就近原则

## 七、备考建议

1. **单词天天背**：3500 词滚动记忆，配合错题集的《单词卡.md》翻卡记忆
2. **语法系统过一遍**：重点攻克非谓语、三大从句、虚拟语气、倒装——单选和完形必考
3. **真题限时练**：阅读 4 篇 40 分是大头，每天 1-2 篇保持手感
4. **写作背模板**：准备开头/中间/结尾万能句型，考前默写 3-5 篇不同类型范文
5. **错题入库**：词汇语法错题按格式抄进《错题集\错题本.md》，用复习页滚动复习

## 八、语法专项速查卡（单选/完形/翻译高频考点）

### 1. 时态（先找时间标志词）
- **现在完成**：since / for / already / yet / so far → have/has done
- **过去完成**：by the time + 过去时 / before 过去动作 → had done（"过去的过去"）
- **过去将来**：would do；**进行时**：at this time yesterday（过去进行）、now（现在进行）
- **主将从现**：if/when/unless + 现在时表将来

### 2. 虚拟语气（三档）
- 与**现在**相反：if + did/were，主句 would/could/should + do
- 与**过去**相反：if + had done，主句 would/could + have done
- 与**将来**相反：if + were to / should do
- **wish 从句**：对现在 were/did，对过去 had done
- **固定句型**：It's (high) time that + did；would rather + did；as if + 虚拟

### 3. 非谓语动词（三选一：doing / done / to do）
- 逻辑主语与动词是**主动** → doing；**被动** → done；**表目的/将来** → to do
- 固定搭配：enjoy/finish/avoid/consider/mind + doing；decide/plan/want/refuse + to do
- **have sth. done**：让别人做/遭受；**make sb. do**（被动 to do）；**see sb. doing/do**
- 独立主格：with + n. + doing/done/to do（表伴随/原因）

### 4. 三大从句
- **定语从句**：先行词是人 who/whom/whose，是物 which/that，时间 where=in which，地点 when；**作宾语可省略**；whose 表所属
- **名词性从句**（主语/宾语/表语/同位语）：that（陈述）/ whether（是否）/ 疑问词
- **状语从句**：although/though（让步）、because（原因）、so that（目的）、as soon as（时间）

### 5. 倒装（否定词/Only 开头）
- **部分倒装**：Never / Hardly / Not only / Only + 状语 / So...that 位于句首 → 助动词/情态/be 提前
- 完全倒装：here/there/now + 谓语 + 主语（名词）

### 6. 主谓一致（一眼定单复）
- **the number of + 复数名词** → 单数；**a number of + 复数名词** → 复数
- each/every/either/neither + 单数；**就近原则**：not only A but also B、there be（看最近的名词）
- 时间/距离/金额作整体 → 单数；集合名词 family/team 看整体或成员

### 7. 高频易混词辨析
- few/little（几乎没，否定）；a few/a little（有一点，肯定）——可数用 few，不可数用 little
- rise/raise：rise 不及物（升起/上涨）；raise 及物（举起/提高/抚养）
- except（除...外，不包括）/ besides（除...外还有）/ except for（整体肯定+局部例外）
- sometime（某时）/ some time（一段时间）/ sometimes（有时）/ some times（几次）
- lie（躺/说谎）/ lay（放置/下蛋）；win（赢比赛）/ beat（打败对手）

### 8. 写作万能句型（≥100 词作文）
- 开头：With the development of..., ... / As we all know, ...
- 承转：On the one hand... on the other hand... / What's more, ...
- 举例：For example, ... / Take ... as an example
- 结尾：In conclusion, ... / Only in this way can we ...
