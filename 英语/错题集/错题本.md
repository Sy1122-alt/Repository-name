# 英语 · 错题本

> 这是英语错题的**唯一数据源**。每次做完题，把错题按下面格式追加进去；需要复习时运行 `D:\专升本学习\错题本\build.py`（或直接让我来更新），会自动生成同目录 `复习页.html`。
> 生词记忆请用同目录《单词卡.md》，复习页里也有单词卡入口。

---

## 一、格式说明

- 每条错题用 `## Q-序号` 开头，序号递增。
- 每个字段用 `- 字段名：值` 单独一行（中英文冒号均可）。
- **可用字段**（不涉及的可以不写）：

| 字段 | 必填 | 说明 |
| --- | --- | --- |
| 章节 | 必填 | 见下方章节预设 |
| 题目 | 必填 | 题干（阅读题可贴原文+问题） |
| 答案 | 必填 | 正确答案 |
| 解析 | 推荐 | 为什么对/为什么错，涉及语法点写清楚 |
| 选项 | 选填 | `A. xx / B. xx / C. xx / D. xx` 斜杠分隔 |
| 题型 | 选填 | 单选 / 完形 / 阅读 / 翻译 / 写作 |
| 知识点 | 选填 | 如"虚拟语气""定语从句" |
| 错因 | 选填 | 词汇不懂 / 语法不清 / 理解偏差 / 粗心 |
| 错误次数 | 选填 | 重复做错几次就写几（默认 0，>0 会进"重点题"） |
| 日期 | 选填 | 做错日期 |
| 状态 | 选填 | 待复习 / 已掌握 |

## 二、章节预设（可按考纲增改）

- 01-词汇与词组
- 02-语法
- 03-阅读理解
- 04-完形填空
- 05-翻译
