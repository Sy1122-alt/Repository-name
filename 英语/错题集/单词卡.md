# 英语 · 单词卡

> 这是生词表的**唯一数据源**（翻卡记忆用）。运行 `D:\专升本学习\错题本\build.py` 后生成同目录 `单词卡.html`，双击打开：看到单词 → 默念释义 → 点「翻看释义」核对 → 按掌握程度点「认识 / 模糊 / 不认识」。

---

## 一、格式说明

- 每条生词用 `## W-序号` 开头，序号递增。
- 每个字段用 `- 字段名：值` 单独一行。
- **可用字段**：

| 字段 | 必填 | 说明 |
| --- | --- | --- |
| 单词 | 必填 | 英文单词/短语 |
| 释义 | 必填 | 中文释义 |
| 音标 | 选填 | `/əˈbændən/` |
| 词性 | 选填 | v. / n. / adj. 等 |
| 例句 | 选填 | 帮助记忆的句子 |
| 词根 | 选填 | 词根词缀拆分，助记 |
| 状态 | 选填 | 待复习 / 已掌握 / 模糊（在网页里点按钮更新，也可直接改这里） |
