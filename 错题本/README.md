# 专升本错题本 · 总说明

三科错题统一管理系统。数据源是各学科错题集目录里的 Markdown 文件，`build.py` 把它们解析成可双击打开的交互复习页。

## 目录结构

```
D:\专升本学习\
├─ 错题本\                    ← 总控目录
│  ├─ index.html              ← 三科总入口（双击打开，从这里进各科复习页）
│  ├─ build.py                ← 通用构建工具（一次生成三科页面）
│  └─ README.md               ← 本说明
├─ 计算机\错题集\
│  ├─ 错题本.md               ← 计算机错题数据源
│  └─ 复习页.html             ← 计算机复习页（build.py 生成）
├─ 高数\错题集\
│  ├─ 错题本.md               ← 高数错题数据源（支持 LaTeX 公式）
│  └─ 复习页.html             ← 高数复习页（build.py 生成）
└─ 英语\错题集\
   ├─ 错题本.md               ← 英语错题数据源
   ├─ 复习页.html             ← 英语复习页（build.py 生成）
   ├─ 单词卡.md               ← 英语生词表数据源
   └─ 单词卡.html             ← 单词翻卡记忆页（build.py 生成）
```

## 日常使用流程

1. 双击根目录的 `启动错题本.bat`，浏览器会自动打开总入口；保持弹出的窗口处于打开状态。
2. 在题库页做题，错题进入篮子后点「存入错题本」；系统会自动写入对应学科的 `错题本.md` 并更新复习页。同一道题再次入库时，会合并为原题并累计错误次数。
3. 从总入口的「今日学习」开始。它会汇总三科当天到期题，并指出每科最应优先复习的章节。
4. 复习时先作答，再选择「没记住 / 有点模糊 / 掌握」；系统会安排明天、3 天后或递进间隔后的下一次复习。
5. 直接双击 HTML 仍然可用，但受浏览器限制只能导出文本后手动粘贴。

## 三科特点

| 学科 | 数据文件 | 复习页特点 |
| --- | --- | --- |
| 计算机 | 错题本.md | 章节/题型/错因筛选、重点题、今日应复习 + **LaTeX 公式渲染** |
| 高数 | 错题本.md | 同左 + **LaTeX 公式渲染**（`$...$` 行内、`$$...$$` 块级） |
| 英语 | 错题本.md + 单词卡.md | 错题复习页 + **单词翻卡记忆**（认识/模糊/不认识三档） |

## 复习页通用功能

- 总入口：跨三科汇总今日到期题，并显示各科优先章节
- 统计：总题数 / 待复习 / 已掌握 / 掌握率 / 今日到期
- 筛选：章节、状态、错因（计算机/高数多一个题型）
- 模式：随机抽题 / 顺序浏览 / 重点题（错误次数≥2）/ 今日应复习
- 间隔复习：点「显示答案」后按「没记住 / 有点模糊 / 掌握」安排下次复习
- 重复错题合并：同题再次入库时自动累计错误次数并恢复为待复习
- 错因分布：按错因统计错误情况，定位薄弱点
- 错因闭环：复习后可选择本次错因，写回对应错题并生成“章节 × 错因”薄弱点排行
- 同类训练：每道错题会从同章节题库推荐最多 3 道不同题目，点击即可继续练习
- 题库质量检查：总入口构建时扫描错题/题库的必填字段、重复题、答案与选项对应关系、未归类题和解析缺口
- 进度本地保存：标记状态存在浏览器 localStorage，下次打开还在

## 错题 MD 通用格式（详见各学科文件顶部）

```markdown
## Q-001
- 章节：02-导数与微分
- 题目：……
- 答案：……
- 解析：……（支持换行分段）
- 选项：A. xx / B. xx / C. xx / D. xx
- 题型：选择 / 填空 / 计算 / ……
- 知识点：……
- 错因：概念不清 / 计算失误 / 粗心 / ……
- 错误次数：1
- 日期：2026-09-05
- 状态：待复习 / 已掌握
```

单词卡格式：

```markdown
## W-001
- 单词：abandon
- 音标：/əˈbændən/
- 词性：v.
- 释义：放弃；抛弃
- 例句：……
- 词根：……
- 状态：待复习
```

## 质量检查说明

总入口底部会显示最近一次构建的检查结果。红色项目表示需要修正的结构错误，黄色项目表示建议补充的内容（例如解析或错因）；修正 Markdown 后重新运行 `build.py` 即可刷新报告。
